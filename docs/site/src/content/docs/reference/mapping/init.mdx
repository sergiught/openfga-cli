Walk through creating an openfga/mapper mapping file: pick an event, describe the tuples it should produce, and watch the YAML and its output update as you go.

The wizard needs an interactive terminal. The file defaults to mapping.yaml.

## Usage

```sh
ofga mapping init [file] [flags]
```

## Examples

```sh
# Create ./mapping.yaml
ofga mapping init

# Create a named file, overwriting it if it exists
ofga mapping init auth0.yaml --force
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--force` | overwrite the file if it already exists | `false` |
