Analyze an authorization model and report optimization findings in three tiers: safe (rewrites that never change any Check answer), caller (changes in how callers use the model) and tuple (changes in stored tuples). The safe rewrite is shown as a unified diff.

Input: a DSL or JSON model file, or '-' for stdin. The format is auto-detected.

Writing: --write overwrites the model file with the rewritten DSL (DSL files only; it reformats the file and drops comments). --output-file writes the rewritten DSL to another path and also accepts JSON or stdin input. --tier filters only what is reported, never what is written.

Weights: in --json/--yaml output a finding weight of -1 means unbounded (infinite); human output renders it as inf.

Exit codes: 0 success · 1 error · 2 usage (including an invalid model) · 3 benchmark found a check whose answer changed.

## Usage

```sh
ofga model optimize <model-file|-> [flags]
```

## Examples

```sh
  ofga model optimize model.fga
  ofga model optimize model.fga --write
  ofga model optimize model.json --output-file optimized.fga
  ofga model optimize model.fga --tier safe,caller
  cat model.fga | ofga model optimize - --json
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--bench` | benchmark the model before/after the rewrite on an embedded server (exit 3 and no write if any check result changes) | `false` |
| `--depth` | with --bench, synthesized parent-chain depth | `6` |
| `--iterations` | with --bench, timed samples per check | `100` |
| `--output-file` | write the rewritten DSL to this path (nothing is written when no safe rewrite applies) |   |
| `--seed` | with --bench, synthesis seed | `1` |
| `--synth` | with --bench, synthesize tuples even when a workspace is found | `false` |
| `--tier` | tiers to report: safe, caller, tuple (default all; never changes what is written) | `[]` |
| `--workspace` | workspace directory supplying tuples and checks for --bench (default: ofga.yaml found above the model file) |   |
| `--write` | overwrite the model file with the rewritten DSL (reformats and drops comments; DSL files only) | `false` |
