Read the active profile's store, read an identity provider's current state, replay it through a mapping file, and compare the two. With no file argument it uses ./mapping.yaml.

The report lists tuples the provider backs that the store lacks (missing), tuples the store holds under another condition (changed), and tuples the store holds that the provider no longer backs (stale). Only shapes a snapshot rule writes are checked for stale tuples; rules that write anything else are listed as not checked and never change the exit code. A rule takes part when its `when` also names a snapshot type, such as `input.type == "snapshot.organization.member"`.

It then asks before writing the missing and changed tuples (a changed tuple is deleted and written again), and with --prune asks again before deleting the stale ones. --force skips the questions, --dry-run stops after the report. Without a terminal, under --no-input or -o json/yaml, it only reports unless --force is given. The provider is read once, so the result reflects it as of that moment. Auth0 needs a machine-to-machine application and reads at most 1,000 users.

Exit codes: 0 no drift, or all of it fixed · 1 error · 2 usage · 3 drift remains · 4 network · 130 interrupted.

## Usage

```sh
ofga mappings drift [file] --provider <name> [flags]
```

## Examples

```sh
# See what differs between the store and Auth0
ofga mappings drift auth0.yaml --provider auth0 --dry-run

# Fix it, including stale tuples, without the prompts
ofga mappings drift auth0.yaml --provider auth0 --auth0-client-secret-file ./secret --prune --force
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--auth0-client-id` | Auth0 machine-to-machine client ID (else $AUTH0_CLIENT_ID) |   |
| `--auth0-client-secret-file` | file holding the client secret (else $AUTH0_CLIENT_SECRET) |   |
| `--auth0-domain` | Auth0 tenant domain (else $AUTH0_DOMAIN) |   |
| `--auth0-tenant` | tenant name for display (default: the first label of the domain) |   |
| `-n, --dry-run` | show the drift without writing anything | `false` |
| `-f, --force` | write without asking | `false` |
| `--provider` | identity provider to read (auth0) |   |
| `--prune` | also delete stale tuples the provider no longer backs | `false` |
