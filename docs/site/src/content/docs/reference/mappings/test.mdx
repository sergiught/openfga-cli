Run a mapping file's tests: block with openfga/mapper's runner. Each test evaluates its input and compares the tuples (and tuple filters) produced with the ones it expects. With no file argument it uses ./mapping.yaml.

Exit codes: 0 all passed · 3 a test failed · 1 the file does not compile, has no tests, or --run matched none · 2 usage.

## Usage

```sh
ofga mappings test [file] [flags]
```

## Examples

```sh
ofga mappings test
ofga mappings test sync/auth0.yaml --run member
ofga mappings test --report junit --report-file mapping-tests.xml
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--fail-fast` | stop at the first failing test | `false` |
| `--report` | write a report in this format ("junit", "json", or "github"); to --report-file if set, otherwise printed to the terminal |   |
| `--report-file` | path to write the --report file to (requires --report) |   |
| `--run` | run only tests whose name contains this text |   |
