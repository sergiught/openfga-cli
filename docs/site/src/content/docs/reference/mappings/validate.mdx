Compile a mapping file with openfga/mapper and report every problem with its line and column. With no file argument it uses ./mapping.yaml.

Pass --model-file (offline) or --model-from-store to also check that the authorization model has every type, relation and user type the mapping's tuples and tuple filters name. Without either, the model is not checked.

Exit codes: 0 valid · 1 invalid or error · 2 usage · 4 network.

## Usage

```sh
ofga mappings validate [file] [flags]
```

## Examples

```sh
# Check ./mapping.yaml
ofga mappings validate

# Check against a model file, in CI
ofga mappings validate sync/auth0.yaml --model-file model.fga
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--model-file` | check against an authorization model file (.fga or .json) |   |
| `--model-from-store` | check against the active profile's store model (--model-id, or the latest) | `false` |
