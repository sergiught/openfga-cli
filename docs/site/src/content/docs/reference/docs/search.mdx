Search the OpenFGA documentation. Queries are sent to openfga.dev.

## Usage

```sh
ofga docs search <query...> [flags]
```

## Examples

```sh
  ofga docs search contextual tuples
  ofga docs search "conditions" --max-results 3
  ofga docs search modeling roles --json
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--max-results` | maximum number of results | `5` |
