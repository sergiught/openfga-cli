List the relations a user has on an object. Without --relation, every relation defined on the object's type in the latest authorization model is tested; --relation narrows that to the ones you name (repeatable).

This issues one batch-check per chunk of relations, so it needs OpenFGA >= 1.8.0.

## Usage

```sh
ofga query list-relations [user] [object] [flags]
```

## Examples

```sh
  ofga query list-relations user:anne document:roadmap
  ofga query list-relations --user user:anne --object document:roadmap
  ofga query list-relations user:anne document:roadmap --relation viewer --relation editor
```

## Flags

| Flag | Description | Default |
| --- | --- | --- |
| `--context` | JSON object of condition context |   |
| `--contextual-tuple` | contextual tuple as user,relation,object (repeatable) | `[]` |
| `--object` | object (alternative to the positional arg) |   |
| `--relation` | relation to test (repeatable; default: every relation on the object's type) | `[]` |
| `--user` | user (alternative to the positional arg) |   |
